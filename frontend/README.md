# Todo Categories Frontend

Next.js App Router frontend for the Todo with Categories project.

## Deployed

```txt
https://ui-top-fullstack-v1wq.vercel.app/
```

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

The app starts on:

```txt
http://localhost:3000
```

The backend API URL is configured with:

```txt
NEXT_PUBLIC_API_URL=http://localhost:4000
```
